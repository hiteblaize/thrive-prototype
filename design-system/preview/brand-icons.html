Iconography

Two systems, one rule: no emoji, no unicode symbols. Bespoke pencil-stroke icons for the patient-app workout/vitals vocabulary; Lucide (as CDN stand-in for Font Awesome 6 Pro) for everything else. All rendered inline as SVG so there are no font-loading failures.

Licensing note: production uses Font Awesome 6 Pro (licensed kit). Lucide-style SVG is the prototype substitute — same stroke weight (1.75px), same rounded terminals, CDN-safe. Bespoke workout icons (Workout, METs, Lungs icon, Heart icon, Weight, BP, Effort, Trophy, Group, Check, ArrowUp, ArrowDown) ship as project SVGs and are not replaced.
